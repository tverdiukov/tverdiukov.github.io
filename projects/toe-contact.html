Toe Contact workflow 00:49

Problem → solution

Correct the contact.
Keep the motion.

Animated toes can pass through the ground when footwear, keys and rig controls do not line up perfectly. Toe Contact recalculates only the requested frames, restores believable support and leaves natural airborne motion alone.

01 / Select frames

Use the range already in focus

Run the solve from selected Graph Editor keys, a Time Slider range or the current frame without rebuilding the shot setup.

02 / Solve contact

Keep the front of the foot above the floor

The workflow derives the toe direction and scale per leg, then corrects the front footwear contact against a horizontal world floor.

03 / Preserve toe-off

Support only while it is reachable

The toe stays supported near the ground, releases naturally in the air and preserves an intentionally raised pose. The complete operation is one Maya Undo step.

Technical notes Open details

Geometry-aware contact

The solve uses the front shoe region when its geometry is reliable and falls back to captured contact data when it is not. Heel and midsole contact remain part of the Foot IK workflow.

Animated Rig integration

Toe Contact is a focused workflow inside Tkv Animated Rig, not a separate product. It can bake the result directly or work with the existing editable TOP and SIDE toe controls.
